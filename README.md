# ⛏️ Data Mining

This repository contains my implementations and solutions for a university-level **Data Mining** course.

The project consists of multiple exercise sheets covering key concepts in **unsupervised learning, causal inference, and deep learning**.

---

## 📚 Topics Covered

### 1️⃣ Clustering (Exercise Sheet 1)

- K-Means clustering
- Hierarchical clustering
- Distance metrics
- Cluster evaluation
- Visualization of cluster assignments
- Data preprocessing for clustering

Files:
- `ExerciseSheet1_Clustering.ipynb`
- `exercisesheet1_clustering.py`

---

### 2️⃣ Causality (Exercise Sheet 2)

- Causal inference basics
- Confounders and treatment effects
- Correlation vs. causation
- Statistical analysis for causal reasoning

Files:
- `ExerciseSheet2_Causality.ipynb`
- `exercisesheet2_causality.py`
- `ExerciseSheet2_Causality.pdf`

---

### 3️⃣ Deep Learning (Exercise Sheet 3)

- Neural networks
- Model training and evaluation
- Loss functions
- Optimization techniques
- Basic deep learning pipelines

Files:
- `ExerciseSheet3_DeepLearning.ipynb`
- `exercisesheet3_deeplearning.py`

---

## 🚀 How to Run

### Install dependencies:

```bash
pip install numpy pandas matplotlib scikit-learn
```

For deep learning libraries are required:

```bash
pip install tensorflow
pip install torch
```

---

### Run notebooks:

```bash
jupyter notebook
```

Open the desired exercise notebook.
